# Engineering-Calculations-Hub
This is a website with many useful calculation tools for engineers. Some of the tools is designed specifically for FRC competitors.

# Key Features
- The calculations shown can be done automatically:
    - Wheel speed
    - Gear ratio 
    - Torque 
    - Drivetrain Speed 
    - Chain lenght 
    - Ohm's Law 
    - Resistor Value Calculator(By using colours)
- All the calculators uses many different types of related units.
- A page that shows different useful mechanisms is included. 
- The mechanism page includes CAD files and a contact e-mail for a request of differently sized mechanisms is included.
